Managing month
The Base Pay and Bonus columns below apply to this month. To fix an earlier month, pick it here (e.g. June), changes save to that month's register only. Each month is independent, so fixing one never changes another.
CreatorStatusContractContactBase Pay (₦/month)Bonus (This Month)JoinedLeftPosts (month)Action

How these columns work

Contract: 📄 opens the signed PDF if one has been filed, or searches your Google Drive by that creator's name if it hasn't (in case a copy exists but never got linked automatically). The line underneath tells you what's outstanding. Handled it another way (a phone call, they showed you in person) but the file still isn't in Drive? Click "mark resolved" so it stops showing as outstanding; "reopen" undoes that any time.
Contact: 💬 opens WhatsApp with a pre-written follow-up message asking about their contract, using the phone number they gave at intake. Greyed out means no phone number is on file.
Base Pay: each creator's monthly base pay. Changing it here updates the payment register, the per-video rate (base pay ÷ 62) and the legend instantly. Only shown for active creators.
Bonus (This Month): pick the views milestone a creator hit and the bonus is entered into this month's payment register automatically. Add as many as they earn; use "Remove last" or "Clear all" to fix mistakes. Same tiers for everybody.
Joined: the date the creator was added to the roster (from the sheet).
Left: recorded automatically on the day you press Deactivate. Reactivating a creator clears it. For creators deactivated before this feature existed, the date of their last logged post is shown instead.
